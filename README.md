# WikiLens - Modern Wikipedia Search Application

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://github.com/Alekhya-commits/Wikipedia-Application)
*A modern, feature-rich web application that allows users to instantly search Wikipedia, explore random articles, and track recent search history with an elegant responsive UI and light/dark theme support.*

## 1. Project Overview

**WikiLens** is a dynamic, responsive web application built using HTML5, CSS3, JavaScript, and Bootstrap. It connects directly with the official Wikipedia API to deliver real-time search results complete with article titles, summary snippets, and direct links to full articles. 

Designed with a sleek aesthetic, it features a dark/light theme toggle, recent search history tracking, and an animated loading spinner for a seamless user experience.

## 2. Live Application
* **GitHub Repository:** [WikiLens Repository](https://github.com/Alekhya-commits/Wikipedia-Application)
* **Source Files:** `index.html`, `wiki.css`, `wiki.js`

## 3. Key Features

- **Instant Wikipedia Search:** Query the Wikipedia database in real time with responsive input handling.
- **Dynamic Results Display:** Renders search results dynamically with clear descriptions and direct external links to Wikipedia pages.
- **Random Article Discovery:** Allows users to explore random Wikipedia entries with a single click.
- **Recent Searches & History Management:** Tracks recent user queries locally and provides an option to clear search history.
- **Light & Dark Theme Toggle:** Fully responsive theme switcher with custom icons stored for user preference.
- **Modern UI / UX:** Built with Bootstrap, custom CSS animations, and a polished search interface featuring a loading wave spinner.
